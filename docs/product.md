# 企画書：激安・超簡単Secrets管理SaaS

## 1. 概要

チーム開発におけるAPIキー・トークン・環境変数管理を**最小コスト・最小手間**で解決する開発者向けSaaS。

Webダッシュボードでキーを発行・管理し、Node.js側ではSDKをimportするだけで環境変数が自動設定される体験を提供する。

---

## 2. 背景・課題

### 現状の問題

* `.env` をSlackやDMで共有してしまう
* 新メンバー参加時の環境構築が面倒
* GitHubへの誤push事故
* AWS Secrets Managerなどは設定が重すぎる

### 既存サービスの課題

* 高機能だが**高価**
* CLI・設定ファイルが多く学習コストが高い
* 小規模チーム・学生にはオーバースペック

---

## 3. 解決策（提供価値）

### コンセプト

**「Resend並みに簡単、でもSecrets管理」**

### 体験イメージ

```ts
import { loadSecrets } from "@service/node";

await loadSecrets();
```

* 設定不要
* CLI不要
* 即使える

---

## 4. ターゲットユーザー

### メインターゲット

* 2〜10人規模のチーム開発者
* 複数環境で開発するエンジニア（API Keyひとつで環境変数を持ってこれるため）
* スタートアップ初期
* 学生・ハッカソンチーム
* フリーランス複数案件持ち

### 想定ユースケース

* Webアプリ（Next.js / Express / NestJS）
* APIサービス
* 個人〜小規模SaaS

## 5. 主な機能（MVP）

### Webダッシュボード

* プロジェクト作成

* Backend: Node.js / TypeScript
