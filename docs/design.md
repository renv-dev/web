# Renv LP デザイン指示書

## 目的

Renvは、チーム開発における `.env`（環境変数）の共有と管理を、**最小の手間・最小の学習コスト**で実現する開発者向けSaaSである。

LP（ランディングページ）では以下を明確に伝える：

* `.env` 共有の面倒さを解決するサービスであること
* Node.js 開発者向けに最適化されていること
* 「import して load するだけ」という圧倒的な簡単さ

---

## ターゲットユーザー

* Node.js / TypeScript 開発者
* 2〜10人規模のチーム開発
* スタートアップ初期・個人開発者
* `.env` を Slack や DM で共有した経験がある人

### 4. コード体験セクション（最重要）

コードがこのLPの主役。
視線を最優先で集める。

```ts
import { Renv } from "@renv/node";

const client = new Renv(token);
client.load();
```

* このコードを実行すると、
  ダッシュボードで設定した環境変数が
  自動的に `process.env` に追加されることを
  一目で理解できる構成にする

---

### 5. How it works

3ステップで完結することを強調：

1. ダッシュボードで環境変数を設定
2. トークンを発行
3. SDKを import & load
